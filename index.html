Containerized Energy Generator Frame (Hyliion)

Structural Development • Weldment Design • Supplier Coordination

  • Reduced component count by ~40 parts (~7% from ~600 baseline) via architecture consolidation.
  • Reduced primary C-channel thickness from 3/8" → 1/8" where margins permitted (material/cost/assembly simplification).
  • Increased minimum natural frequency 8 Hz → 31 Hz via strategic X-bracing and gusseting.
  • Validated transport (5g) + operational (3g) load cases using ANSYS (static/modal) and strain energy/load path checks.
  • Performed AWS D1.1 weld stress analysis using FEA-extracted forces/moments (fillet + CJP).

Rotary Evaporator Vacuum System Redesign (Vascular BioSciences)

Root Cause Problem Solving • Fluid/Vacuum System • Process Optimization

  • Increased throughput from ~1 cycle/day → 6–8 cycles/day.
  • Cut cost per cycle from ~$6–7 (electric) → ~$1–3 (water), ~70–85% savings.

High-Pressure Hydrogen Generation System (Capella Partners)

Design + Prototyping • Safety-Critical Materials • Pressure/Vacuum Testing

  • Designed and prototyped a hydrogen generation system operating at ~400 psi with H₂/O₂ isolation.
  • Built three CAD iterations (300+ part assembly) incorporating test feedback and DFA/DFM.
  • Upgraded gasket material to PTFE after thermal compatibility review (rubber near melt limit).
  • Identified gas permeability risk in FDM part via pressure + soap bubble testing; redesigned in 6061-T6 → zero leaks.
  • Created production-ready drawings with GD&T and material specs; collaborated with local shops.
