Rotary Evaporator Vacuum System Redesign

Vascular BioSciences • Jan 2024 – Jun 2025 • Process Optimization & Root Cause Problem Solving

Problem

The drug development team was bottlenecked by rotary evaporator (rotovap) cycle time: ~48 hours per evaporation cycle. The constraint was not technical performance—it was operating cost. Continuous electric vacuum pumps were too expensive to run continuously for a startup.

Root Cause Analysis

  • 48-hour cycle time limited research velocity and experimentation throughput.
  • Primary driver: no continuous vacuum capability in daily operation.
  • Why no vacuum? Electric pumps were cost-prohibitive to run continuously.
  • Root cause: economic constraint (operating cost), not a fundamental technical limitation.

Solution: Water Aspirator Vacuum (Venturi Effect)

  • Implemented a venturi-based water aspirator: high-velocity water flow creates a low-pressure region that draws vacuum.
  • Designed and assembled the system using standard NPT fittings and clear PVC tubing.
  • Systematically troubleshot the vacuum path:
    • Sealed leaks with high-vacuum silicone grease at interfaces
    • Optimized tubing diameters for flow / pressure drop tradeoffs
    • Validated connections via pressure/leak checks
  • Created a simple SOP for end-users: “turn on faucet gradually to create vacuum.”

Engineering Rationale

  • Lower absolute pressure reduces solvent boiling point → faster evaporation at the same temperature.
  • Enabled faster evaporation without overheating temperature-sensitive compounds.

Validation

  • Validated through 12+ months of daily use with consistent 4-hour cycle times across repeated experiments.
  • Outcome: research throughput unlocked—6–8 cycles/day vs. 1 cycle per ~48 hours.

What This Demonstrates

  • Root cause thinking: reframed the problem from “pump cost” to “deliver vacuum function within constraints.”
  • System-level optimization: physics + economics + operations, not just “build a part.”
  • Troubleshooting discipline: component-level validation → full system integration.
  • Metrics-driven impact: quantified and sustained improvements.
